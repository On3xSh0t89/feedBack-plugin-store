Plugin Store manages the official got-feedBack plugin catalog and optional third-party stores that you explicitly add.

Third-party stores are unreviewed. Their plugins can execute server-side Python and browser JavaScript with feedBack's permissions. Plugin Store validates store structure, repository manifests, ids/versions, and minHost compatibility, but that validation is not a malware scan.

Plugin changes are written to FEEDBACK_PLUGINS_DIR. After a lifecycle change, Plugin Store can restart feedBack by terminating the application process; Docker or another supervisor must be configured to start it again.

Before plugin updates, Plugin Store keeps bounded rollback snapshots under CONFIG_DIR/plugin_store/backups. The default is two snapshots per plugin and can be changed with FEEDBACK_PLUGIN_STORE_BACKUPS_PER_PLUGIN.
