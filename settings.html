Plugin Store installs only curated repositories from the official got-feedBack GitHub organization.

When this plugin is installed with git clone, it automatically checks the registry.yaml from its own GitHub origin. ZIP installs use the bundled registry unless FEEDBACK_PLUGIN_STORE_REGISTRY_URL is configured.

Plugin changes are written to FEEDBACK_PLUGINS_DIR. After a change, Plugin Store can restart feedBack by terminating the application process; Docker will start it again when a restart policy is configured.
