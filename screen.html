Add Third-Party Store

Third-party plugins execute code inside feedBack.

A malicious plugin can read or modify files available to the feedBack container, access feedBack data, and make network requests. Third-party stores are not reviewed or endorsed by the feedBack project. Only add a store you trust.

v0.2 accepts GitHub-hosted YAML stores. The link is fetched and validated before the store is saved.
